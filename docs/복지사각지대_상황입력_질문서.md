# 취약계층 공공지원사업 안내 서비스 — 상황 입력 질문서

_기획서 별첨. 지원을 받기 위해 실제로 필요한 정보(A)와 이를 얻기 위한 문답 스크립트(B)_

## A. 지원을 받기 위해 실제로 필요한 정보

노인·소득취약 대상 주요 지원사업이 심사 시 요구하는 정보를 역산한 목록이다. 금액 기준(선정기준액, 중위소득 비율 등)은 매년 보건복지부 고시로 바뀌므로 문서에 숫자를 박지 않고 **시스템에서 연도별 파라미터로 관리**한다.

## B. 상황 입력 문답 스크립트

### B.0 구조와 규칙

```
[공통 6문항]  나이 · 사는 곳 · 같이 사는 사람 · 자녀 · 지금 받는 것 · 가장 필요한 도움
      ↓ 필요한 도움에 따라 분기
[분기 모듈]   A 생활비 / B 병원비 / C 식사·혼자 생활 / D 이동 / E 집 / F 안전   (모듈당 2~4문항)
      ↓
[마무리 2문항]  신분증·통장 · 방문 가능 여부
      ↓
[되읽기 확인]  → 보호자 보완
```

- 본인이 답하는 질문은 **최대 12개**. 한 화면 한 질문, 선택지 최대 4개(복수선택 제외), 모든 질문에 [잘 모르겠어요].
- 본인이 알기 어려운 것(자녀 소득·재산, 공시가격, 연금 정확한 금액 등)은 **처음부터 본인에게 묻지 않는다.** 보호자 화면에서만 묻는다.
- [잘 모르겠어요]는 보호자 보완 목록으로 이동. "괜찮아요, 나중에 도와주시는 분께 여쭤볼게요."
- 자유 답변은 LLM이 구조화 후 B.11 되읽기에서 확인.
- `→` 분기, `[보호자]` 보호자 보완 항목, `[매핑]` 심사 조건 변환.

---

### B.1 시작

> 받을 수 있는 지원이 있는지 함께 알아볼게요.
> 질문은 10개쯤이에요. 모르는 건 넘어가셔도 돼요.
> [제가 직접 알아볼게요] [어르신을 도와드리려고 해요]

보호자 선택 시: [자녀·가족] [요양보호사·활동지원사] [복지사·공무원] [이웃·지인] → 이후는 어르신 기준으로 답변. 보호자 유형은 B.12 보완 화면 구성에 쓰인다.

### B.2 공통 질문 (모두에게)

**Q1. 나이**
> 몇 년에 태어나셨어요?
> (연도 4자리 입력 / 또는 "만 65세가 넘으셨어요?" [네] [아니요])

[매핑] 65세 기준 대상군 진입.

**Q2. 사는 곳**
> 지금 어디에 살고 계세요?
> (시·도 → 시·군·구 → 읍·면·동 버튼 선택)

[보호자] 주민등록상 주소가 다르면 알려주기
[매핑] 관할 주민센터, 지자체 사업 필터.

**Q3. 같이 사는 사람**
> 지금 집에 누구랑 같이 살고 계세요?
> [혼자 살아요] [배우자와] [자녀·손주와] [다른 사람과]

→ [혼자 살아요]: "배우자분은요?" [돌아가셨어요] [따로 살아요] [없어요]
→ [자녀·손주와]: "같이 사는 분이 돈을 벌어요?" [네] [아니요] [모르겠어요]
[보호자] 배우자 사망 시 유족연금 여부, 동거 가구원 소득
[매핑] 가구원 수(중위소득 기준선), 단독/부부(기초연금), 동거 자녀는 부양의무자가 아닌 같은 가구로 합산.

**Q4. 자녀**
> 아드님·따님이 계세요?
> [네, 연락도 잘 돼요] [있는데 연락이 잘 안 돼요] [있는데 아예 끊겼어요] [없어요]

→ [없어요]: 자녀 관련 전부 건너뜀.
→ [연락이 잘 안 돼요] / [아예 끊겼어요]:
> 마지막으로 연락한 게 언제쯤이에요?
> [1년 안] [1~3년] [3년 넘게] [기억 안 나요]

본인에게는 여기까지만 묻는다. 자녀의 직업·소득·재산·결혼 여부 등은 **묻지 않는다.** 보호자가 자녀인 경우 B.12에서 자녀가 직접 답한다.
[매핑] 부양의무자 존재 여부, 관계 단절(부양 기피·거부 소명 대상). 되읽기: "자녀분과 ○년 넘게 연락이 안 되는 상황으로 이해했어요. 맞으세요?"

**Q5. 지금 받는 것**
> 지금 나라에서 받고 있는 게 있으세요? 해당하는 걸 모두 눌러 주세요.
> [기초연금] [생계비(생계급여)] [병원비 지원(의료급여)] [집세 지원(주거급여)] [없어요] [잘 모르겠어요]

[보호자] 수급자·차상위 여부 (복지로 '나의 복지 정보', 수급자 증명서)
[매핑] 중복 제외, 수급자 연계 감면(에너지·통신·문화누리) 자동 추천. "모르겠어요"는 주민센터 조회 항목으로 메시지에 포함.

**Q6. 가장 필요한 도움** (분기 결정)
> 지금 가장 필요한 도움은 무엇인가요? 여러 개 골라도 돼요.
> [생활비가 부담돼요] [병원비가 걱정돼요] [식사를 챙기기 어려워요] [혼자 생활하기 어려워요] [외출이나 이동이 어려워요] [집과 관련된 도움이 필요해요] [혼자 있을 때 안전이 걱정돼요] [잘 모르겠어요]

분기 규칙:

| 선택 | 이어지는 모듈 |
|---|---|
| 생활비 | A |
| 병원비 | B (+ A의 소득 질문 1개) |
| 식사 / 혼자 생활 | C |
| 외출·이동 | D |
| 집 | E (+ A의 소득 질문 1개) |
| 안전 | F |
| 잘 모르겠어요 | A + C의 첫 질문 (기본 모듈) |

복수 선택 시 모듈 합집합, 중복 질문은 한 번만. 합쳐서 분기 질문이 6개를 넘으면 우선순위(생활비 > 병원비 > 집 > 혼자 생활 > 식사 > 이동 > 안전)로 잘라내고 나머지는 보호자 보완 목록으로.

### B.3 모듈 A — 생활비

**A1. 들어오는 돈**
> 한 달에 어르신 앞으로 들어오는 돈을 다 합치면 얼마쯤이에요? 연금, 일해서 번 돈, 자녀가 주는 돈 다 포함이에요.
> [30만 원 아래] [30~60만 원] [60~100만 원] [100만 원 넘게] [잘 모르겠어요]

[보호자] 통장 기준 월 입금 합계, 연금 종류(공무원·군인·교직원 연금이면 기초연금 제외)
[매핑] 소득인정액 1차 추정.

**A2. 돈이 어디서 들어오는지**
> 그 돈은 주로 어디서 들어와요? 해당하는 걸 모두 눌러 주세요.
> [나라에서 주는 연금] [일해서 버는 돈] [자녀·친척이 주는 돈] [없어요]

→ [일해서 버는 돈]: "어떤 일이세요?" (자유 입력 / [넘어갈게요])
[매핑] 공적이전·근로·사적이전 소득 구분, 비공식 소득 신고 안내, 근로능력.

**A3. 사는 집**
> 지금 사시는 집은요?
> [제 집이에요] [전세·월세예요] [자녀·친척 집이에요] [잘 모르겠어요]

→ [전세·월세예요]: "보증금이랑 월세가 얼마예요?" (구간 / [잘 모르겠어요])
[보호자] 자가면 공시가격, 전월세면 계약서(보증금·월세·계약자), 사는 집 외 다른 부동산·예금 대략
[매핑] 일반재산·금융재산은 보호자 답변으로 보완. 본인에게는 집 형태까지만.

**A4. 최근 큰 일**
> 최근 몇 달 사이에 이런 일이 있었어요?
> [가족이 돌아가시거나 집을 나갔어요] [크게 아프거나 다쳤어요] [일자리를 잃었어요] [전기·가스가 끊겼거나 끊길 것 같아요] [없어요]

[매핑] 긴급복지지원 위기 사유. 있으면 결과 최상단 + "빨리 가셔야 해요".

### B.4 모듈 B — 병원비

**B1. 병원**
> 어디가 아파서 병원에 다니세요?
> (자유 입력 / [말하기 어려워요])
> 병원비가 얼마나 부담되세요?
> [많이] [조금] [괜찮아요]

[매핑] 의료급여 필요도, 긴급복지(중한 질병), 질환별 의료비 지원.

**B2. 장애·등급**
> 장애 등록이나 요양등급(장기요양등급)을 받으셨어요?
> [장애 등록 있어요] [요양등급 있어요] [둘 다 없어요] [모르겠어요]

[매핑] 장애·장기요양 연계 사업, 미등록 시 등록 안내.

(+ A1 소득 질문)

### B.5 모듈 C — 식사·혼자 생활

**C1. 거동**
> 혼자서 장 보고 식사 준비하는 게 어떠세요?
> [혼자 다 해요] [힘들지만 해요] [못 해요]

→ [힘들지만 해요] / [못 해요]:
> 씻고, 화장실 가는 것도 도움이 필요하세요?
> [혼자 해요] [조금 필요해요] [많이 필요해요]
[매핑] 노인맞춤돌봄 필요도, 장기요양 등급 신청 대상.

**C2. 요양등급**
> 요양등급(장기요양등급)을 받으셨어요?
> [네] [신청했는데 안 됐어요] [아니요] [그게 뭔지 모르겠어요]

[매핑] 등급 있음 → 재가서비스, 노인맞춤돌봄 중복 불가. 없음 + C1 어려움 → 등급 신청 안내.

**C3. 기억력**
> 요즘 깜빡하는 게 많이 늘었다고 느끼세요?
> [치매 진단 받았어요] [걱정돼요] [괜찮아요]

[매핑] 치매안심센터, 인지지원등급.

### B.6 모듈 D — 외출·이동

**D1. 이동**
> 밖에 나가실 때 어떠세요?
> [혼자 다녀요] [지팡이·보행기 있으면 다녀요] [누가 같이 가야 해요] [거의 못 나가요]

**D2. 장애 등록**
> 장애 등록이 되어 있으세요?
> [네] [아니요] [모르겠어요]

→ [아니요]: "다리·눈·귀가 많이 불편하신데 등록은 안 하셨어요?" [그래요] [괜찮아요]
[매핑] 장애인 이동지원(콜택시·보조기기), 장애 등록 안내, 방문 신청 필요 여부.

### B.7 모듈 E — 집

**E1. 사는 집**
> 지금 사시는 집은요?
> [제 집이에요] [전세·월세예요] [자녀·친척 집이에요] [잘 모르겠어요]

→ [전세·월세예요]: "보증금이랑 월세가 얼마예요?" (구간 / [잘 모르겠어요]) + "계약서가 어르신 이름이에요?" [네] [아니요] [모르겠어요]
[보호자] 임대차계약서 확인
[매핑] 주거급여(부양의무자 기준 없음 → 자녀 단절과 무관하게 추천 가능), 보증금 재산 반영.

**E2. 집 문제**
> 집 때문에 어떤 게 걱정이세요?
> [집세를 못 내고 있어요] [나가라고 해요] [집이 낡거나 추워요] [그냥 알아보고 싶어요]

[매핑] 긴급복지(퇴거 위기), 주거급여 수선유지, 에너지바우처, 공공임대.

(+ A1 소득 질문)

[매핑] 응급안전안심서비스(감지기·응급호출), 노인맞춤돌봄 안전확인, 치매 연계.

### B.9 마무리 (모두에게)

**Q11. 신분증·통장**
> 주민등록증(또는 운전면허증)과 어르신 이름으로 된 통장이 있으세요?
> [둘 다 있어요] [신분증만 있어요] [통장만 있어요] [둘 다 없어요]

→ 통장 있으면 "어느 은행이에요?" (은행 선택, 계좌번호는 묻지 않음)

### B.12 보호자 보완 화면

보호자는 링크로 들어와 **미답변 항목 + 보호자에게만 묻는 항목**을 본다. 보호자 유형에 따라 구성이 다르다.

**보호자가 자녀·가족일 때 — 자녀 본인 기준으로 답한다**

> 어르신 지원 심사에서는 자녀분 형편도 함께 봅니다. 정확하지 않아도 괜찮고, 심사는 주민센터에서 합니다.
> - 형제자매를 포함해 자녀가 몇 분이세요? (숫자)
> - 본인은 지금 일을 하세요? [직장인] [자영업] [무직] [수급자·차상위예요]
> - 본인 월 소득은 대략? (구간 / [답하기 어려워요])
> - 본인 명의 집이 있으세요? [네] [아니요]
> - 어르신께 생활비를 드리고 계세요? [매달] [가끔] [아니요]
> - 다른 형제자매 형편도 아시면 알려주세요 (자유 입력 / [모르겠어요])

**보호자가 요양보호사·복지사·이웃일 때 — 자녀 형편은 묻지 않는다**

자녀 관련 항목은 "자녀분께 이 링크를 전달해 주세요"로 별도 링크 생성. 연락 두절이면 "연락 두절 상황을 아시는 대로 적어주세요(기간·사유·확인 가능한 사람)"만 묻는다.

**공통 보완 항목 (본인이 [잘 모르겠어요]한 것만 표시)**

| 항목 | 문구 | 확인 방법 |
|---|---|---|
| 주민등록 주소 | 어르신 주민등록상 주소가 실제 사는 곳과 다르면 알려주세요 | 정부24 등본 |
| 연금 종류·금액 | 받는 연금 종류와 월 수령액 | 국민연금공단 앱, 통장 |
| 월 소득 합계 | 통장 기준 한 달 입금 합계(대략) | 은행 앱 |
| 집 | 자가면 공시가격, 전월세면 보증금·월세·계약자 | 공시가격알리미, 계약서 |
| 다른 재산 | 사는 집 외 집·땅, 예금·보험 대략, 팔거나 쓸 수 있는지 | 등기부, 은행·보험 앱 |
| 유족연금 | 배우자 사망 시 유족연금 수령 여부 | 연금공단 |
| 현재 수급 여부 | 수급자·차상위·기초연금 수급 여부 | 복지로, 수급자 증명서 |
| 진단·등급 | 진단명, 장애 등급, 장기요양 등급 | 진단서, 판정서 |

보호자가 저장하면 본인 화면에 "도와주시는 분이 답을 채워주셨어요"가 뜨고 되읽기가 갱신된다.
